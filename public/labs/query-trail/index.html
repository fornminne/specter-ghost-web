// 01 · LEARN

SQL PARAMETERIZATION

Building SQL by concatenating untrusted strings changes the query structure. Parameterized statements keep values separate from SQL syntax.

LEARNING GOAL

Identify the failure from the supplied synthetic evidence and explain a defensive fix.

// 02 · INVESTIGATE

EVIDENCE

UNSAFE: sql = "SELECT * FROM items WHERE sku='" + sku + "'"
SAFE: sql = "SELECT * FROM items WHERE sku=?"; db.execute(sql,[sku])
review_marker=parameters_not_patches
HINT

The safe version binds the sku as a value.
