// 01 · LEARN

API AUTHORIZATION BASICS

APIs expose resources through endpoints like GET /api/v1/projects/17. A bearer token identifies a client, but identification is not permission.

AUTHENTICATION VS AUTHORIZATION

Authentication asks who is making a request. Authorization asks whether that person may access this particular project. Multi-tenant systems must enforce object ownership on every request.

BOLA / IDOR

Broken Object Level Authorization (BOLA), also called IDOR, happens when an API accepts an object ID but fails to verify access rights. A successful response containing another tenant's private project is suspicious.

DEFENSIVE PATTERN

project = db.projects.find(id)
if project is None: return 404
if project.tenant != user.tenant: return 403
return project.public_view()

Real applications also consider roles and explicit sharing rules.

// 05 · DEBRIEF

WHY THIS HAPPENED

The tenant-alpha token retrieved projects belonging to both alpha and bravo. The server authenticated the requester without consistently enforcing ownership of the requested object.

HOW TO FIX IT

Scope project queries to the authenticated tenant, enforce authorization on every object, test cross-tenant negative cases, and remove debug markers from production responses.
