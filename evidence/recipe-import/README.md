# Recipe-import evidence

These HTML files are synthetic lab evidence for a recipe-import exercise. They are not part of the public portal and must not be copied under `public/`.

AWS Amplify publishes only the `public/` directory (`amplify.yml`). Anything placed there is served from the portal origin. These fixtures stay in `evidence/` so they can be reviewed and, later, attached to an isolated lab that is not `specterghost.com`.

Treat every file here as untrusted evidence. Do not render it as a SPECTER.GHOST page, and do not point the portal at it.
